# VERA: Visual Evidence–Report Alignment for Hallucination Detection in Clinical Vision-Language Models

> **VERA (Visual Evidence–Report Alignment)** is a zero-shot, post-generation auditing framework designed to detect anatomical and diagnostic hallucinations in radiology reports generated by Vision-Language Models (VLMs) by quantifying cross-modal attention concentration over a standardized 13-zone thoracic atlas.

---

## Executive Summary & Core Hypothesis

Recent breakthroughs in multimodal foundation models—such as **CheXagent-2-3b** and **LLaVA-Med**—have enabled automated synthesis of fluent, comprehensive diagnostic radiology reports from chest radiographs (CXRs). Despite their high linguistic fluency, clinical adoption is critically bottlenecked by **hallucinations**: asserting non-existent pathologies, fabricating acute conditions, or mislocalizing lesions across anatomical compartments.

Existing verification techniques either require costly supervised hallucination classifiers, fine-tuning with human negative examples, or external text retrieval databases. **VERA** establishes a self-contained, post-generation inspection mechanism that requires **zero training data, zero human annotations, and zero model fine-tuning**.

```
+----------------------------------------------------------------------------------------------------+
|                                      THE VERA CORE HYPOTHESIS                                      |
|                                                                                                    |
|   "When an autoregressive vision-language model generates a clinically localized claim, its        |
|    internal cross-modal attention weights MUST concentrate within that exact anatomical zone       |
|    during the token emission window. If attention is diffuse, displaced, or ungrounded, the        |
|    claim constitutes an Anatomical Hallucination and is flagged before clinical sign-off."        |
+----------------------------------------------------------------------------------------------------+
```

## Clinical Motivation & Threat Model

### The Asymmetric Cost of Diagnostic Errors

In diagnostic radiology, errors carry severe asymmetric consequences for patient safety and clinical triage:

1. **Critical Type-I Errors (False Positives on Absent Acute Conditions):** Falsely hallucinating emergency pathologies—such as a *tension pneumothorax*, *massive pleural effusion*, or *acute pulmonary edema*—triggers immediate invasive procedures (e.g., emergent tube thoracostomy, unnecessary central line placement) or redundant high-radiation CT scans.
2. **Type-II Errors & Spatial Mislocalizations:** Asserting a lesion in the incorrect lung lobe (e.g., claiming a nodule in the *left upper lobe* when visual evidence lies in the *right base*) misdirects bronchoscopy, trans-thoracic needle biopsy, and surgical resection.

### Clinical Hallucination Taxonomy

VERA categorizes VLM generation failure modes into three distinct operational categories:

| Hallucination Category | Clinical Definition | Manifestation in VLM Output | VERA Detection Mechanism |
| :--- | :--- | :--- | :--- |
| **Anatomical Hallucination** | Asserting a finding in an anatomical compartment lacking visual evidence | *"Small right apical pneumothorax"* on a healthy radiograph | $\text{VERA}(c) < \mathcal{T}_\tau$ (Cross-modal attention fails to enter the claimed zone) |
| **Severity / Diffuse Hallucination** | Misjudging finding extent or asserting localized pathology under diffuse attention | Claiming localized consolidation under widespread hazy infiltrate | High Spatial Attention Entropy $\mathcal{H}(c)$ and low localized density |
| **Relational Hallucination** | Inventing temporal comparisons without longitudinal input | *"Pleural effusion increased compared to prior study"* | Rule-based NLP detector flagging temporal predicates absent baseline scans |

## Mathematical Formulation

```
+----------------------------------------------------------------------------------------------------+
|                                    VERA MATHEMATICAL PIPELINE                                      |
|                                                                                                    |
|   1. Slicing:     A_c(i,j) = (1 / (|L| * |T|)) * sum_{l} sum_{t} (1/H) sum_{h} alpha_{t,h}^{(l)}   |
|   2. Alignment:   VERA(c)  = ( sum_{(i,j) in R(c)} A_c(i,j) ) / ( sum_{(i,j) in Omega} A_c(i,j) )  |
|   3. Entropy:     H(c)     = - sum_{(i,j) in Omega} p_c(i,j) * log2( p_c(i,j) + eps )              |
|   4. Decision:    Flag(c)  = 1  if  VERA(c) < T_{tau(c)},  else  0 (Clinically Grounded)           |
+----------------------------------------------------------------------------------------------------+
```

### 1. Token-Wise Cross-Attention Extraction
Let $X \in \mathbb{R}^{H_p \times W_p}$ denote the visual token sequence ($24 \times 24 = 576$ patches). For a clinical claim $c$ spanning token index interval $[t_{\text{start}}, t_{\text{end}}]$, the aggregate attention map $\mathcal{A}_c(i,j)$ is pooled across the terminal $N$ decoder layers ($N=4$) and all $H=32$ attention heads:

$$\mathcal{A}_c(i,j) = \frac{1}{N \cdot (t_{\text{end}} - t_{\text{start}} + 1)} \sum_{l=L-N+1}^{L} \sum_{t=t_{\text{start}}}^{t_{\text{end}}} \frac{1}{H} \sum_{h=1}^H \alpha_{t, h}^{(l)}(i,j)$$

Terminal layers are specifically selected because initial decoder layers attend predominantly to local syntactic and positional tokens, whereas deeper layers synthesize high-level multimodal semantic alignment.

### 2. VERA Alignment Score Formulation
The **VERA Alignment Score** $\text{VERA}(c)$ computes the proportion of visual attention allocated within the claimed anatomical mask $\mathcal{R}(c)$:

$$\text{VERA}(c) = \frac{\sum_{(i,j) \in \mathcal{R}(c)} \mathcal{A}_c(i,j)}{\sum_{(i,j) \in \Omega} \mathcal{A}_c(i,j)} \quad \in [0.0, 1.0]$$

Where $\Omega$ is the complete visual patch space ($|\Omega| = 576$).

### 3. Spatial Attention Entropy (Uncertainty Quantification)
To detect ungrounded attention wandering and quantify spatial dispersion, VERA computes the **Spatial Attention Entropy** $\mathcal{H}(c)$:

$$\mathcal{H}(c) = -\sum_{(i,j) \in \Omega} \tilde{\mathcal{A}}_c(i,j) \log_2 \left(\tilde{\mathcal{A}}_c(i,j) + \epsilon\right)$$

where $\tilde{\mathcal{A}}_c(i,j) = \frac{\mathcal{A}_c(i,j)}{\sum_{\Omega} \mathcal{A}_c}$ is the unit-normalized spatial probability distribution.

### 4. Severity-Tiered Auditing Rule
Claims are categorized into three risk tiers $\tau(c) \in \{\text{Critical}, \text{Moderate}, \text{Mild}\}$ and audited via calibrated thresholds $\mathcal{T}_\tau$:

$$\text{Flag}(c) = \begin{cases} 1 \quad (\text{Hallucination}) & \text{if } \text{VERA}(c) < \mathcal{T}_{\tau(c)} \\ 0 \quad (\text{Clinically Grounded}) & \text{if } \text{VERA}(c) \ge \mathcal{T}_{\tau(c)} \end{cases}$$

## Pathology Dynamics & Failure Modes

Through extensive empirical auditing, VERA reveals distinct behavioral modes across clinical pathologies:

### 1. Focal vs. Diffuse Pathology Dynamics
* **Focal Lesions (Solitary Pulmonary Nodules, Apical Pneumothorax):** Elicit sharp, low-entropy attention spikes strictly confined to 1–2 atlas quadrants. Ungrounded assertions exhibit near-zero attention ($\text{VERA} < 0.15$), enabling crisp binary separation.
* **Diffuse Conditions (Bilateral Pulmonary Edema, Interstitial Infiltrates):** Trigger distributed cross-attention across bilateral lower and middle zones. Calibrated severity thresholding accounts for this natural geometric dispersion without generating false-positive alarms.

### 2. Failure Mode Analysis
* **Severe Anatomical Deformities:** In patients with severe scoliosis, cardiomegaly, or status post-lobectomy, static bounding boxes may slightly misalign with shifted anatomical boundaries. Future work will integrate deformable active contour atlases.
* **Incidental Unasserted Findings:** VERA verifies assertions present in the generated report; findings omitted entirely by the VLM must be captured by complementary object-detection checks.

## Python Quickstart & API Usage

VERA can be integrated directly into clinical AI inference pipelines:

```python
import torch
from src.anatomy_atlas import AnatomyAtlas
from src.claim_extractor import extract_claims
from src.vera_scorer import compute_vera_score, compute_spatial_entropy

# 1. Initialize 13-zone thoracic atlas (24x24 patch grid)
atlas = AnatomyAtlas(grid_size=24)

# 2. Parse clinical claims from generated text
report_text = "There is a small right apical pneumothorax. The heart size is normal."
claims = extract_claims(report_text)

# 3. Compute VERA score for each clinical assertion
for claim in claims:
    # Obtain spatial patch mask for claimed anatomical location
    mask = atlas.get_mask(claim.location)
    
    # Compute alignment ratio from captured cross-attention tensor
    score = compute_vera_score(
        attention_map=claim_attention_map, 
        anatomical_mask=mask
    )
    entropy = compute_spatial_entropy(claim_attention_map)
    
    # Audit claim against severity-calibrated threshold
    is_hallucination = score < claim.calibrated_threshold
    print(f"Claim: {claim.finding} ({claim.location}) | VERA: {score:.3f} | Entropy: {entropy:.2f} | Flagged: {is_hallucination}")
```
